# 关于我 / About Me

你好，我是 SnowyChangAnRoad，一个人工智能专业大二学生。

建立本站点的初衷是打造一个属于自己的互联网栖身之所，记录自己的想法和喜欢的东西，分享给朋友们。

感谢你愿意来到这里，愿你能享受在这里停留的时间。

## 关于本站

本站基于开源的 **Firefly** 博客模板搭建，由 Astro 驱动生成纯静态页面，界面使用 Svelte 岛屿与 Tailwind CSS，搜索由 Pagefind 提供，代码高亮使用 Expressive Code。文章以 Markdown 编写，构建后部署在自有的云服务器上，通过 Nginx 托管，运行时不需要数据库或后端服务，访问轻快、维护简单。这里记录我的文章、照片与一些零散想法。
